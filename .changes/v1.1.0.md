## 🏷️ [v1.1.0](https://github.com/shambles07/choretrack/releases/tag/v1.1.0) · <sub>November 22, 2026</sub>

### ✨ Added

- Release-candidate tags (e.g. `v1.1.0-rc.1`) are published as GitHub pre-releases

### 🎨 Changed

- Parent login: Tab wraps between the username and password fields, fields turn green when filled in correctly, and the Log in button is shown as the default action with a prompt to press Return/Enter
- Every form now works like the parent login: Tab wraps around, fields turn green when valid and red (with a tooltip) when not, Return/Enter submits from any field, and the submit button is shown as the default action
- Docker Compose now defaults to the America/Chicago time zone (set `TZ` in `docker-compose.yml` to change it)

### 🐛 Fixed

- The parent login and first-run setup forms now put the cursor in the first field when they open, so Tab moves through the form instead of jumping to the page header
- `make tag` explains when changie isn't installed yet, confirms the tag actually reached GitHub, and pushes a tag that was created but never pushed
- `make release` no longer fails at the last step with a shell quoting error
