# ⌨️ Keyboard shortcuts

[← Back to README](../README.md)

Press a number to jump to that page in the sidebar. Hold a modifier key to see the numbers next to each page.

> [!NOTE]
> ChoreTrack reads your browser's user agent to work out your operating system, and shows the matching keys in the app: **⌃ ⌥** on macOS and iPadOS, **Ctrl Alt** on Windows, Linux, ChromeOS and FreeBSD.

## Show the numbers

| Action | 🍎 macOS | 🪟 Windows · 🐧 Linux · 😈 FreeBSD |
| --- | :---: | :---: |
| Show shortcut numbers | Hold <kbd>⌃</kbd> or <kbd>⌥</kbd> | Hold <kbd>Ctrl</kbd> or <kbd>Alt</kbd> |

## Elsewhere

| Where | Key | Does |
| --- | :---: | --- |
| PIN pad | <kbd>0</kbd>–<kbd>9</kbd> | Types a digit |
| PIN pad | <kbd>⌫</kbd> | Deletes a digit |
| Any dialog | <kbd>Esc</kbd> | Closes it |

> [!TIP]
> Shortcuts pause while you're typing in a field or a dialog is open, so typing <kbd>5</kbd> into a search box won't jump to People. <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + number is left to the browser for switching tabs.
