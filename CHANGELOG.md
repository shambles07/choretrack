## 🏷️ [v1.0.0](https://github.com/shambles07/choretrack/releases/tag/v1.0.0) · <sub>November 21, 2026</sub>

### ✨ Added

- Parent portal to manage chores, people, categories and rewards, and to approve or send back finished chores with a note
- Kid dashboard with avatar-and-PIN login, a daily progress ring, and card or table views with an icon for each chore category
- Points, XP levels, day streaks, 12 trophies and a reward shop. Points only count once a parent approves
- Confetti and synthesised jingles when a chore is done, and a "Collect!" fanfare when points are approved, with a mute switch and reduced-motion support
- Light and dark themes that follow your device, with a manual toggle
- Each person's favourite colour becomes the accent colour, with button text that stays readable
- Live red/green validation with icons and tooltips on name and PIN fields
- Number-key page shortcuts. Hold Ctrl/Alt (⌃/⌥ on a Mac) to see them; the right keys are detected from your browser
- Click your avatar or name to edit your own profile
- Installable as a home-screen app (PWA)
- Command-line flags: `--port`, `--export chores|users|scores|all`, `--version` and `--usage`
- Makefile for installing, updating to the latest release, deploying with Docker, exporting data and cutting releases
- Versioned releases tracked with changie, published as GitHub releases when a tag is pushed
- Ready-made Docker Compose, systemd (Raspberry Pi / Debian) and launchd (macOS) setups, listening on port 3030

### 🔒 Security

- Passwords and PINs hashed with scrypt, hashed session tokens in HttpOnly cookies, rate-limited logins, JSON-only write requests and a Content Security Policy
